# Disclaimer: this project is fully vibe coded

Folia is being written entirely by an AI coding assistant, Claude (made by Anthropic), working in
[Claude Code](https://claude.com/claude-code). Its code, tests, scripts, documentation, plans and
this disclaimer are generated by the assistant in conversation with the project's maintainer, who
describes what they want, reviews the results and asks for changes. No line of it is written by
hand.

## What that means

- **It is tested, not audited.** Changes are checked with automated checks (`just check`) and,
  for output parity, against production builds of the Jekyll site Folia replaces. Nobody reviews
  the code line by line the way a careful human-written project would be.
- **Expect rough edges.** Bugs that the checks did not reveal are likely. Please
  [report them](https://github.com/ggirelli/folia/issues).
- **It is built for one website.** Folia publishes [ggirelli.info](https://ggirelli.info). It is
  not meant as a general-purpose static-site generator, and nothing promises it will suit yours.
- **No warranty.** As the [license](LICENSE) says, the software is provided "as is".

## Why say it

Because it is true, and because you should know how the software you run was made. The commit
history shows the whole process: each commit is co-authored by the assistant.
